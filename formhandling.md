# Handling Forms with Formilk #100

## What is formik
Formik is a React form library that manages form values, validation errors, touched fields, and submission logic for you, so you need less repetitive state-handling code. Yup works well with Formik because you can define validation rules in one schema instead of manually checking each field.

## How does Formik simplify form management compared to handling state manually?

Formik manages form values, errors, touched fields, and submission in one place, reducing the amount of repetitive useState and event-handler code needed.

## What are the benefits of using Formik’s validation instead of writing validation logic manually?
Formik can integrate with Yup so validation rules are defined in a reusable schema, making validation cleaner, more consistent, and easier to maintain.
