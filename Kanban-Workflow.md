## 📝 Reflection

**1. How does Kanban help manage priorities and avoid overload?**
*   Kanban visually enforces limits. When working on a full-stack project, it is easy to try and build the frontend UI, design the database schema, and write the backend endpoints all at once. Kanban forces me to prioritize the immediate blocker, ensuring I don't become overwhelmed by trying to juggle too many complex technical contexts simultaneously.

**2. How can you improve your workflow using Kanban principles?**
*   I can improve my workflow by breaking down large epics into smaller, independently deployable tasks. For example, instead of a single card for "Build Settings Page," I can break it down into "Create API endpoint for user preferences" and "Implement toggle UI components," allowing the cards to move smoothly across the board rather than stalling in the "In Progress" column for a week.
