# Chrome Extensions Setup & Reflection

## 1. Which extensions did you install? Why?
*   **React Developer Tools:** I installed this because inspecting the component tree and viewing live props and state is essential when working with React.js and Next.js. It simplifies tracking down exactly where a UI issue is originating.
*   **Redux DevTools:** This extension makes debugging global state much more manageable. The time-travel debugging feature allows me to step through state changes sequentially, which is invaluable when complex data flows through the application.
*   **JSON Viewer:** I installed this to automatically format and colorize API responses directly in the browser tab. It makes reading raw data payloads infinitely easier compared to a raw text string.
*   **Lighthouse:** I added this extension to run immediate, automated checks on my web projects. It provides a standardized way to assess whether my code meets best practices for accessibility and performance.

## 2. What was the most useful thing you learned?
The most useful thing I learned is how these tools integrate seamlessly with the existing browser developer tools. Instead of relying on external software or countless console logs, I can now profile component rendering times, inspect API structures, and generate comprehensive performance audits all from within the same browser window. This unified workflow drastically speeds up the debugging process.
