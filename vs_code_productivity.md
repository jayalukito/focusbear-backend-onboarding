# VS Code Productivity & Shortcuts
**Role:** Developer Intern

## 10 Essential VS Code Shortcuts

### Navigation
1.  **Quick Open (Go to File):** `Ctrl/Cmd + P` - Instantly search and open any file in the workspace.
2.  **Global Search:** `Ctrl/Cmd + Shift + F` - Search for specific text or variables across the entire project.
3.  **Toggle Sidebar:** `Ctrl/Cmd + B` - Hide or show the file explorer to maximize screen space.

### Editing
4.  **Multiple Cursors (Click):** `Alt/Option + Click` - Insert multiple cursors to edit several lines simultaneously.
5.  **Select Next Occurrence:** `Ctrl/Cmd + D` - Selects the next instance of the currently highlighted word for quick bulk renaming.
6.  **Format Document:** `Shift + Alt/Option + F` - Automatically formats the current file based on language settings.

### Debugging
7.  **Start/Continue Debugging:** `F5` - Launches the debugger or continues execution to the next breakpoint.
8.  **Toggle Breakpoint:** `F9` - Quickly add or remove a breakpoint on the current line.
9.  **Step Over:** `F10` - Execute the next line of code without stepping into function calls.

### Terminal Commands
10. **Toggle Integrated Terminal:** `Ctrl/Cmd + \`` - Opens or hides the built-in terminal.
11. **New Terminal:** `Ctrl/Cmd + Shift + \`` - Spawns a fresh terminal instance for running concurrent processes.

## 📝 Reflection

**1. Which shortcuts do you think will be the most useful in your daily work?**
The multiple cursor shortcuts (`Alt/Option + Click` and `Ctrl/Cmd + D`) will be the most impactful. When I am refactoring C# classes, updating state variables in Next.js components, or tweaking configuration settings for MongoDB, being able to type once and edit multiple lines simultaneously saves a tremendous amount of manual work. Additionally, the Quick Open (`Ctrl/Cmd + P`) shortcut is indispensable for jumping rapidly between frontend views and backend API routes.

**2. How can keyboard shortcuts improve your productivity?**
Keyboard shortcuts keep me in a state of flow. Every time I have to take my hand off the keyboard to reach for the mouse to toggle the terminal or find a file, it breaks my concentration. By committing these shortcuts to muscle memory, I can navigate the codebase, execute Python scripts, run NUnit tests, and manage Git commands at the speed of thought.
